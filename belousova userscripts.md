# Пользовательские сценарии

**Проект:** Платформа для поиска партнёров (учебные/проектные мероприятия)  
**Автор:** Белоусова М.  
**Файл:** `belousova_userscripts.md`


## Сценарий №1- Пользователь регистрируется и авторизуется

1. Пользователь открывает главную страницу приложения и нажимает кнопку «Зарегистрироваться».
2. Пользователь вводит имя, электронную почту и пароль в соответствующие поля.
3. Система проверяет корректность введённых данных (формат email, длина пароля).
4. Если email уже занят, система отображает сообщение об ошибке: «Пользователь с таким адресом уже существует».
5. Система отправляет письмо с подтверждением на указанный email.
6. Пользователь переходит по ссылке из письма и подтверждает регистрацию.
7. Пользователь вводит email и пароль на странице входа и нажимает «Войти».
8. Система проверяет данные; если пароль неверен, отображается сообщение об ошибке с указанием оставшихся попыток.
9. После успешного входа система перенаправляет пользователя на главную страницу с персонализированным меню.



## Сценарий №2- Пользователь создаёт объявление

1. Авторизованный пользователь нажимает кнопку «Создать объявление» в главном меню.
2. Пользователь вводит заголовок объявления и выбирает категорию из выпадающего списка.
3. Пользователь заполняет текстовое поле с описанием.
4. Пользователь прикрепляет фотографию через кнопку «Добавить фото».
5. Система проверяет, что обязательные поля (заголовок, категория, описание) заполнены.
6. Если обязательное поле не заполнено, система выделяет его красным и выводит подсказку.
7. Пользователь нажимает кнопку «Опубликовать».
8. Система сохраняет объявление и присваивает ему уникальный идентификатор и дату публикации.
9. Система перенаправляет пользователя на страницу созданного объявления с подтверждением публикации.



## Сценарий №3 - Пользователь редактирует и удаляет объявление

1. Пользователь переходит в личный кабинет и открывает раздел «Мои объявления».
2. Пользователь нажимает кнопку «Редактировать» рядом с нужным объявлением.
3. Система открывает форму с уже заполненными текущими данными объявления.
4. Пользователь изменяет заголовок, описание или фото и нажимает «Сохранить».
5. Система валидирует изменения и сохраняет новую версию объявления.
6. Пользователь возвращается в список «Мои объявления» и нажимает «Удалить» у нужного объявления.
7. Система отображает диалог подтверждения: «Вы уверены, что хотите удалить объявление?»
8. Если пользователь подтверждает, система удаляет объявление и убирает его из всех поисковых результатов.
9. Система отображает уведомление: «Объявление успешно удалено».



## Сценарий №4- Пользователь ищет объявления

1. Пользователь вводит ключевое слово в строку поиска на главной странице.
2. Пользователь нажимает кнопку «Найти» или клавишу Enter.
3. Система выполняет поиск по заголовкам и описаниям объявлений.
4. Система отображает список объявлений, соответствующих запросу, с превью и датой.
5. Если совпадений нет, система выводит сообщение: «По вашему запросу ничего не найдено» и предлагает изменить запрос.
6. Пользователь нажимает на интересующее объявление.
7. Система открывает страницу объявления с полным описанием, фото и данными автора.
8. Пользователь имеет возможность сразу написать автору через кнопку «Написать».
9. Система фиксирует просмотр объявления и обновляет счётчик.



## Сценарий №5 - Пользователь управляет личным кабинетом

1. Авторизованный пользователь нажимает на своё имя или аватар в правом верхнем углу.
2. Система открывает личный кабинет с разделами: «Мои объявления», «Сообщения», «Настройки».
3. Пользователь переходит в «Настройки» и изменяет имя или фото профиля.
4. Пользователь нажимает «Сохранить изменения».
5. Система обновляет данные и отображает уведомление об успешном сохранении.
6. Пользователь переходит в раздел «Мои объявления» и видит список всех своих публикаций со статусами.
7. Система отображает статистику: количество просмотров каждого объявления.
8. Пользователь нажимает «Экспортировать» и скачивает список своих объявлений в формате PDF.
9. Система формирует и загружает PDF-файл со всеми объявлениями пользователя.



## Сценарий №6 -Пользователь просматривает профиль другого пользователя

1. Пользователь открывает страницу объявления другого пользователя.
2. Пользователь нажимает на имя или аватар автора объявления.
3. Система открывает публичный профиль автора с именем, аватаром и датой регистрации.
4. Система отображает список активных объявлений данного пользователя.
5. Пользователь прокручивает список и нажимает на одно из объявлений.
6. Система открывает страницу выбранного объявления.
7. Пользователь возвращается в профиль и нажимает кнопку «Написать сообщение».
8. Система открывает окно чата с этим пользователем.
9. Если пользователь заблокирован, система выводит сообщение: «Написать этому пользователю невозможно».



## Сценарий №7- Пользователь общается через встроенный чат

1. Пользователь открывает страницу объявления и нажимает кнопку «Написать».
2. Система создаёт диалог между пользователем и автором объявления (если он ещё не существует).
3. Пользователь вводит текст сообщения в поле ввода и нажимает «Отправить».
4. Система отправляет сообщение и отображает его в диалоге с меткой времени.
5. Автор объявления получает уведомление о новом сообщении.
6. Если адресат не отвечает в течение длительного времени, система отображает статус «не отвечает».
7. Пользователь переходит в раздел «Сообщения» в личном кабинете, чтобы увидеть все диалоги.
8. Система отображает список диалогов, отсортированных по дате последнего сообщения.
9. Пользователь открывает нужный диалог и продолжает переписку.



## Сценарий №8-Пользователь фильтрует объявления по датам

1. Пользователь находится на странице поиска или в списке объявлений.
2. Пользователь нажимает кнопку «Фильтры».
3. Система открывает панель фильтров с полями «Дата от» и «Дата до».
4. Пользователь выбирает начальную дату через встроенный календарь.
5. Пользователь выбирает конечную дату.
6. Если конечная дата раньше начальной, система выводит ошибку: «Некорректный диапазон дат».
7. Пользователь нажимает «Применить».
8. Система фильтрует объявления и отображает только те, что опубликованы в указанный период.
9. Система отображает количество найденных результатов и предоставляет кнопку «Сбросить фильтры».



## Сценарий №9- Система проверяет актуальность объявлений

1. Система автоматически раз в неделю отправляет автору уведомление: «Ваше объявление “[название]” ещё актуально?»
2. Пользователь открывает уведомление и нажимает кнопку «Да, актуально».
3. Система обновляет дату подтверждения и сохраняет объявление активным.
4. Если пользователь нажимает «Нет, снять», система деактивирует объявление.
5. Если пользователь не реагирует в течение 7 дней, система автоматически скрывает объявление из поиска.
6. Скрытое объявление остаётся в личном кабинете пользователя со статусом «Неактивно».
7. Пользователь видит неактивное объявление в разделе «Мои объявления» и нажимает «Восстановить».
8. Система возвращает объявление в активный статус и обновляет дату публикации.
9. Система отображает подтверждение: «Объявление снова активно».
